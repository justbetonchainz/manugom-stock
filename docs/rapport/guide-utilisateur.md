# Guide utilisateur

## Client

Créer un compte, ouvrir le catalogue, appliquer les filtres, consulter une fiche, choisir une quantité et ajouter au panier. Dans le panier, modifier ou retirer les lignes, puis valider l'adresse, le mode de réception et le paiement. La commande apparaît dans « Mes commandes » et peut être annulée tant que son état le permet.

## Employé

Se connecter puis ouvrir « Gestion ». Ajouter ou modifier les références, enregistrer un mouvement, traiter les commandes dans l'ordre des statuts, créer les approvisionnements et surveiller les alertes.

## Administrateur

En plus des opérations employé, gérer les comptes, les marques, catégories et fournisseurs. Utiliser l'archivage plutôt que la suppression d'un élément déjà référencé.
