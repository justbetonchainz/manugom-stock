# Technologies

- Python 3.14 et Django 6.1.1 : serveur, MVT, ORM, formulaires, sessions, sécurité et tests.
- SQLite : base relationnelle unique et migrations Django.
- HTML5, CSS3, JavaScript : structure, identité jaune/noir et interactions légères.
- Bootstrap 5.3 et Bootstrap Icons : grille responsive, composants et iconographie.
- Chart.js 4.5 : cinq visualisations du tableau de bord ; ce n'est ni un langage ni une technologie backend.
- Pillow : validation et prise en charge des champs image.
- StarUML : format de livraison `.mdj`; vérification applicative encore nécessaire faute d'installation locale.
