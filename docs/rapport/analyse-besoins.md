# Analyse des besoins

## Acteurs

- Visiteur : information, recherche, devis, contact et inscription.
- Client : panier, commande, profil et historique personnel.
- Employé : opérations catalogue, clients, commandes, stock et achats.
- Administrateur : capacités employé, utilisateurs et référentiels critiques.

## Besoins fonctionnels

Authentifier, cataloguer, filtrer, commander, suivre, approvisionner, tracer les mouvements, signaler les seuils, présenter les statistiques et archiver sans casser l'historique.

## Besoins non fonctionnels

Validation serveur, protection CSRF, mots de passe Django, interfaces responsives, pagination, cohérence SQLite, code séparé par responsabilité, transactions courtes, messages d'erreur lisibles et données de démonstration identifiées.
